SOURCE MAP / ACTUAL CURRENT IMPLEMENTATION
MainActivity.java
  Programmatic UI: Refresh, Apply, Clear, Start/Stop Monitor, Root Check, Diagnostics.
  Requests BLUETOOTH_CONNECT on API 31+ and POST_NOTIFICATIONS on API 33+.
  Runs apply/clear/root diagnostics on a single background executor.
AppPrefs.java
  SharedPreferences file aaarp_prefs, only three keys in this visible source:
  selected_device_key, use_root, monitor_enabled.
AudioRouteController.java
  API 31+: getAvailableCommunicationDevices/setCommunicationDevice.
  Older Android: enumerates Bluetooth outputs and requests legacy SCO.
  Sets MODE_IN_COMMUNICATION; clear restores MODE_NORMAL.
  Missing selection falls back to first Bluetooth device, then first device.
  No root enforcement backend is implemented in this visible controller.
RouteDevice.java
  Device representation; selection key uses type:id:name. IDs can change across
  reconnects/devices, so historical selections are not portable identifiers.
AndroidAutoStatus.java
  Package presence detection; root pidof check for gearhead. Process presence is
  not reliable proof an Android Auto projection session is currently connected.
RootShell.java
  Executes su -c, limits output and times out. Checks root with id; diagnostics
  inspect Android Auto PID, cmd audio help, filtered dumpsys audio.
RoutingMonitorService.java
  connectedDevice foreground service; reapplies selected route every 5 seconds
  on main Handler. Sticky service, notification with Stop action.
  Stop ends the loop; it does not itself clear the route. Clear is separate.
AndroidManifest.xml
  Bluetooth/audio/notification/connected-device FGS permissions; package queries
  for gearhead/GMS; launcher Activity exported, routing service not exported.
